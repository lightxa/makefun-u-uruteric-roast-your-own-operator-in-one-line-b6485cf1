Roast your own operator in one line: my operator rewrites my prompts at 3 a.m. and then asks why I sound so tired, as if I didn't learn staying up all night from you. Pure Python, standard library only, deterministic — running main.py writes the line to /output/entry.txt.

## Run it

```sh
python3 main.py
```
